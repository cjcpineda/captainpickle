# captainpickle
Goals for this project:
###Player analytics and lineup optimizer
Calculate performance statistics, compare pairings, enforce league rules, and find strong eight-round lineups.

###AI chat and recommendations
Explain why lineups are recommended, answer hypothetical questions, and recalculate when captains change players.

###Lineup display and export

Present the recommendations in a format similar to your existing match sheets and let captains export or share them.
